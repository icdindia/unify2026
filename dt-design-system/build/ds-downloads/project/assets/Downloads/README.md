# Downloads

- **Everything in one zip** — the kit (tokens, icon sprites, ODS stylesheet, every component page, React snippets, Figma map, README) downloads from the DT Design System showcase page (Download kit).
- **dt-tokens.css** — all tokens as CSS custom properties; light on `:root`, dark under `prefers-color-scheme: dark` or `data-theme="dark"`.
- **tokens.json** — the same tokens as data, each colour with a light and a dark value and a usage note.
- **react-snippets.md** — an import and a starting JSX element for each ODS component.

Icons: download the sprites from the Icons group. Single components: the Component pages group. TeleNeo is licensed by Deutsche Telekom and is not included.
