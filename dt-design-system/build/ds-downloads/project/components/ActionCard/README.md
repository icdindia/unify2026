# ActionCard

The Action Card component from the ODS web library.

- **ODS name:** `ODSActionCard`
- **Storybook:** Components/Card (New)/Action Card
- **Stories:** Example, Button

## What the consumer provides

The ODS React component `ODSActionCard` (props above) or, for static HTML, the markup in this card's preview with `bundle.css` loaded. Colours follow the surrounding theme (`data-theme`) and any `data-scheme` wrapper.

## Use it

```tsx
import { ODSActionCard } from "@telekom-ods/react-ui-kit";
// Next.js: import { ODSActionCard } from "@telekom-ods/react-ui-kit/ODSActionCard";

<ODSActionCard />
```

Static HTML: download **ActionCard.html** from Assets › Component pages (markup, DT tokens and the ODS CSS it uses). Everything at once: the kit zip on the DT Design System showcase page.
