# ChoiceCard

The Choice Card component from the ODS web library.

- **ODS name:** `ODSChoiceCard`
- **Storybook:** Components/Card (New)/Choice Card
- **Stories:** Example, Radio Group

## What the consumer provides

The ODS React component `ODSChoiceCard` (props above) or, for static HTML, the markup in this card's preview with `bundle.css` loaded. Colours follow the surrounding theme (`data-theme`) and any `data-scheme` wrapper.

## Use it

```tsx
import { ODSChoiceCard } from "@telekom-ods/react-ui-kit";
// Next.js: import { ODSChoiceCard } from "@telekom-ods/react-ui-kit/ODSChoiceCard";

<ODSChoiceCard />
```

Static HTML: download **ChoiceCard.html** from Assets › Component pages (markup, DT tokens and the ODS CSS it uses). Everything at once: the kit zip on the DT Design System showcase page.
