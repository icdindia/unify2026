# ContainerCard

The Container Card component from the ODS web library.

- **ODS name:** `ODSContainerCard`
- **Storybook:** Components/Card (New)/Container Card
- **Stories:** Example

## What the consumer provides

The ODS React component `ODSContainerCard` (props above) or, for static HTML, the markup in this card's preview with `bundle.css` loaded. Colours follow the surrounding theme (`data-theme`) and any `data-scheme` wrapper.

## Use it

```tsx
import { ODSContainerCard } from "@telekom-ods/react-ui-kit";
// Next.js: import { ODSContainerCard } from "@telekom-ods/react-ui-kit/ODSContainerCard";

<ODSContainerCard />
```

Static HTML: download **ContainerCard.html** from Assets › Component pages (markup, DT tokens and the ODS CSS it uses). Everything at once: the kit zip on the DT Design System showcase page.
