Principles

Build from ODS first

  • Use the ODS packages in code: @telekom-ods/react-ui-kit, @telekom-ods/design-tokens, @telekom-ods/react-icons.
  • Style every part with tokens, never raw values. Start with a background token so a component follows mode and scheme.
  • Mode: data-mode="light" or "dark" on <body>; without it ODS follows the OS.
  • Schemes: wrap a region in data-scheme="magenta", "black" or a palette hue to recolour everything inside.

Sizes in product screens

  • Reading text in chat stays 16px (Body M) on the 760px column.
  • Button and filter labels are 14px (Body S Bold). Text buttons stay 40px tall, the ODS minimum.
  • Compact icon actions use the 24px XSmall icon button with a 16px icon.
  • Side navigation, menu items, table cells and breadcrumbs keep ODS 16px.

Content

  • Keep a line under 80 characters; a body text block no wider than 575px.
  • Titles are clear and short. ODS has no uppercase styles; set text as written.
  • Never convey state by colour alone; pair status colour with an icon and a word.
  • Hit areas are at least 48px (sizing-minimum-tappable-area).

Colour

Semantic tokens from the ODS neutral scheme. Each has a light and a dark value; the swatch column shows the value for the current theme. Text sits on colours-basic-text, magenta is an accent and never a ground.

DT palette

15 secondary hues from ODS, 7 steps each, as --palette-<hue>-<step> and Figma variables palette/<hue>/<step>. Use them for data visualisation, categories, avatars and tints. Put colours-basic-text on the fills (8.7:1 or better on base and lighter); never set text in a palette colour, and keep status on the functional tokens. Dark mode reverses each ramp. Click a swatch to copy its token.

Typography

TeleNeo variable, weight 500 for regular and 700 for bold. Titles are fluid between 360 and 1680px viewports. Letter-spacing is 0 everywhere.
