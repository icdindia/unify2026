# Enterprise Brain prototype

A clickable, responsive React prototype of the Figma file **Enterprise Brain Base 2026 - 1**
(`lqKjNjyifEXCeywg69Knr2`), built on the Unify2026 design-system tokens in `../shared`.
Every screen links back to the Figma frame it reproduces.

## Open it

| You want to… | Do this |
|---|---|
| Look at it or share it | Open `../dist/eb-app.html` in any browser. It is one self-contained file (about 2 MB) that needs no server. Fonts load from Google Fonts, so you need to be online. You can email it or drop it in Slack or Drive. |
| See the latest work while it is being built | From the repo root run `npm --prefix app run dev` and open http://localhost:4190. The page reloads as code changes. |
| Rebuild the shareable file | `npm --prefix app run build`. This type-checks, builds, and rewrites `../dist/eb-app.html`. |
| Run the checks | `bash tools/tests/eb-app/run.sh` (from the repo root). It runs every suite; see `tools/tests/eb-app/README.md`. |

The first time on a new machine, run `npm --prefix app install`.

## Use it for reviews

The **review bar** sits at the top right. On narrow windows it folds into "Review ▾".

- **‹ › and the step picker** walk the built Figma frames in Figma order: journey by journey, step by step.
  With `?unbuilt=show` they walk every frame, and an unbuilt one shows its Figma frame instead.
- **Figma ↗** opens the exact Figma frame for what you are looking at.
- **As designed / With fixes** switches the whole app between the Figma design and the design with the
  proposed or approved fixes applied. The fix log lives in `src/fixes/` and is shown in the gallery.
- **Inside page: Option 1 / 2** (project pages) and **Nav: Dark / Light**.
- **Open at 1440 / 1280 / 1024 / 787 / 390** opens the same screen at that width.

**Only built screens are reachable.** Nav items without a built page (Routines and Meetings today) do
nothing, and the step picker skips unbuilt steps. To see the "Not built yet" Figma placeholders for every step,
open the page with `?unbuilt=show` before the `#`, for example `eb-app.html?unbuilt=show#/routines`.

Useful pages:
- `#/new` starts a chat. Type and press Enter, and the scripted journey plays with Figma's timings.
- `#/projects` is the Projects landing and project dashboard.
- `#/artifacts` is the Artifacts landing: open a card, use its ⋯ menu (Pin, Edit with Chat, Clone, Delete), the type
  filter, search and the list view. Clones, renames, pins and deletes last until the page is reloaded.
- `#/gallery` lists every component on its own, with its Figma component links. This is the dev team's reference.
- `#/gallery/frame-map` lists every mapped Figma frame with the prototype URL that reproduces it. This is the handoff map.

Any URL can be shared: it opens the exact state, for example
`#/chat/commit?at=answer&modal=share&rail=e` is the share dialog over the answer.

## For developers

- Stack: React 19, TypeScript, Vite. Plain CSS sits next to each component and uses only the shared design tokens
  (`tools/verify.sh` enforces this).
- `src/components/*` holds the components. Each root carries `data-node-id` with its Figma node, and each has a gallery page.
- `src/screens/*` holds the screens; `src/app/routes.tsx` maps the routes.
- `src/figma/frames.generated.ts` is the Figma frame ↔ URL map. It is generated by `tools/gen-frames.py` from
  `figma-ref/chat-artifacts/*/journey.json`.
- `src/fixes/*` holds every deliberate departure from Figma, with before, after, reason and status.
- `src/fixtures/*` holds sample people, chats, artifacts and scripted playback.
- `figma-ref/` holds 1440px reference screenshots and per-step specs of the Figma frames. The tests diff the app against them.
